# 08_ECL_Calculation.sas

## Overview

This program calculates Expected Credit Loss (ECL) for the banking portfolio under multiple stress scenarios.

The objective is to combine Exposure at Default (EAD), stressed Probability of Default (PD), and stressed Loss Given Default (LGD) values to estimate potential future credit losses.

This program represents the core risk quantification engine of the Banking Stress Testing Framework.

---

## Purpose

The program calculates Expected Credit Loss (ECL) for each portfolio exposure and aggregates results for portfolio-level analysis.

The calculated ECL values enable comparison of credit losses across:

- Baseline Scenario
- Mild Stress Scenario
- Severe Stress Scenario

---

## Business Importance

Expected Credit Loss (ECL) is one of the most important metrics used in credit risk management.

ECL estimates potential future losses by combining:

- Probability of Default (PD)
- Loss Given Default (LGD)
- Exposure at Default (EAD)

The resulting loss estimates support:

- Credit Risk Management
- Portfolio Monitoring
- Capital Planning
- Stress Testing
- Regulatory Reporting

## ECL Formula

Expected Credit Loss is calculated using:

```text
ECL = EAD × PD × LGD
```

Where:

```text
EAD = Exposure at Default

PD = Probability of Default

LGD = Loss Given Default
```

---

## Processing Activities

### Exposure Retrieval

Retrieves Exposure at Default values for each portfolio record.

---

### PD Integration

Merges stressed Probability of Default values generated during the PD Stress Impact phase.

---

### LGD Integration

Merges stressed Loss Given Default values generated during the LGD Stress Impact phase.

---

### ECL Calculation

Calculates Expected Credit Loss for each exposure using:

```text
ECL = EAD × PD × LGD
```

---

### Scenario-Level Aggregation

Calculates ECL across:

```text
Baseline

Mild_Stress

Severe_Stress
```

for portfolio comparison.

---

### Validation Checks

Performs validation to ensure:

- ECL values are non-negative
- Scenario results are complete
- Aggregated portfolio totals reconcile
