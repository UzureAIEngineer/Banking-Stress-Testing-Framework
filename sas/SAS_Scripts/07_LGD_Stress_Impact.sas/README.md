# 07_LGD_Stress_Impact.sas

## Overview

This program calculates the impact of stress scenarios on Loss Given Default (LGD) for the banking portfolio.

The objective is to estimate how recovery rates and loss severity may change under adverse economic conditions and generate stressed LGD values for Expected Credit Loss (ECL) calculations.

This program is a core component of the Banking Stress Testing Framework and works alongside the PD Stress Impact module.

---

## Purpose

The program applies scenario-based stress adjustments to baseline Loss Given Default (LGD) estimates.

The resulting stressed LGD values are used to assess the potential increase in credit losses under unfavorable economic environments.

---

## Business Importance

Loss Given Default (LGD) represents the proportion of exposure that is expected to be lost when a borrower defaults.

During periods of economic stress:

- Collateral values may decline
- Recovery rates may decrease
- Collection efforts may become less effective
- Loss severity may increase

LGD stress testing enables financial institutions to estimate potential increases in portfolio losses and evaluate capital adequacy under adverse conditions.

## Processing Activities

### Baseline LGD Identification

Retrieves existing LGD values for each portfolio record.

---

### Stress Multiplier Application

Applies scenario-dependent LGD adjustments.

Supported scenarios:

```text
Baseline

Mild_Stress

Severe_Stress
```

---

### Stressed LGD Calculation

Computes stressed Loss Given Default values using predefined stress factors.

Example:

```text
Stressed LGD

=
Baseline LGD × Stress Multiplier
```

---

### LGD Validation

Ensures calculated LGD values remain within acceptable limits:

```text
0 <= LGD <= 1
```

Where required, LGD values exceeding 100% are capped at the maximum allowable level.

---

### Scenario Comparison

Generates stressed LGD estimates across all available scenarios to support comparative analysis.

---

## Outputs

Produces scenario-adjusted LGD values including:

- Baseline LGD
- Stressed LGD
- Scenario Name
- Product Type
- Risk Segment

These outputs are later combined with stressed PD and Exposure at Default (EAD) values during ECL calculations.
