# 10_Export_For_PowerBI.sas

## Overview

This program exports the final reporting datasets generated by the Banking Stress Testing Framework into CSV format for Power BI consumption.

The exported files serve as the reporting layer between SAS and Power BI.

This is the final execution step in the framework.

---

## Purpose

The program converts SAS reporting datasets into dashboard-ready CSV files.

The exported files are consumed by the Power BI Dashboard for executive reporting and visualization.

---

## Business Importance

This module bridges:

Portfolio Stress Testing
↓
SAS Reporting
↓
CSV Export Layer
↓
Power BI Dashboard

and enables interactive business reporting.
