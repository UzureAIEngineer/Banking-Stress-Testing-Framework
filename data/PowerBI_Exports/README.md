# Power BI Export Files

These files were generated from the SAS Banking Stress Testing Framework.

Files:

- ecl_summary.csv
- product_ecl_summary.csv
- segment_ecl_summary.csv

Purpose:

These datasets serve as the reporting layer consumed by the Power BI Dashboard.

Flow:

Portfolio Processing (SAS)
→ Portfolio Reporting
→ CSV Export
→ Power BI Dashboard
