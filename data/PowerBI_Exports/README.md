# Power BI Export Files

These files represent the reporting layer of the Banking Stress Testing Framework.

The datasets used by the Power BI Dashboard are generated by different implementation layers including:

- SAS
- SQL
- Python

Files:

- ecl_summary.csv
- product_ecl_summary.csv
- segment_ecl_summary.csv

Purpose:

These datasets provide summarized portfolio-level reporting for visualization and executive risk reporting.

Data Flow:

Banking Stress Testing Framework
        ↓
Portfolio Reporting Layer
        ↓
Power BI Export Files
        ↓
Power BI Dashboard
